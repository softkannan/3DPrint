Blender can both edit and convert mesh files such as the STL format.

Online conversion tools are good enough for fast and simple models, but larger and more complex ones need bulkier solutions. Here enters [Blender](https://all3dp.com/2/blender-simply-explained/), powerful open-source 3D modeling software used by a range of hobbyists and professionals for animation, simulation, visual effects, and game creation.

Converting STL files to DXF is straightforward with Blender. In case you don’t have it yet, you can download and install the latest version for free on [Blender’s website](https://www.blender.org/download/). It’s available for Windows, MacOS, and Linux.

## **Conversion Steps**

1. Open the program. If this is your first time using Blender, make sure to delete the grey cube model located at the center of the workspace. Do this by left-clicking to select the cube, then right-clicking and selecting “Delete”.
2. Go to “File > Import > Stl (.stl)” and import the model from your computer to Blender. Make sure the model is selected before moving on to the next step.
   
   ![STL-to-DWG-(AutoCAD)_activate-the-dxf-add-on-to-export-in-this-format-w-lucas-carolo-via-all3dp-210422_download.jpg](images/STL-to-DWG-(AutoCAD)_activate-the-dxf-add-on-to-export-in-this-format-w-lucas-carolo-via-all3dp-210422_download.jpg)
   
   You might need to activate the DXF add-on
3. Then, go to “File > Export” and a list of file formats will be displayed. Check if the “AutoCAD DXF” option is available.
4.  If DXF is listed, select it and choose the destination folder for the converted file.

If DXF isn’t listed, you’ll have to add it manually:

1. Navigate to “Edit > Preferences”.
2. Go to the “Add-ons” tab on the left and look for “Import-Export: AutoCAD DXF Format (.dxf)” on the right.
3. Click to enable it (see image above). Now, the AutoCAD DXF format should be listed when you go to export.
4. Go to “File > Export”, then select AutoCAD DXF and choose the destination folder for the converted file.

The newly exported DXF can be directly opened by AutoCAD. Keep in mind that Blender also allows mesh manipulation and 3D modeling, so you might not even need to use AutoCAD! Be sure to check out [some tutorials](https://all3dp.com/2/blender-3d-printing-tutorial-16-easy-steps-for-beginners/) on this beloved software.
